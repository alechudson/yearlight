## Variant: Day motes

### Design stance
One pixel per day. The void fills with light as the year passes — progress is density, not a countable ring.

### Key choices
- Layout: 365 one-pixel stars packed into the map void only
- Typography: unchanged HUD
- Color: elapsed white, today yellow, remaining navy; four seasonal crosses
- Interaction: day-of-year slider

### Trade-offs
- Strong at: actually filling the black; January vs December is obvious at a glance
- Weak at: weeks are no longer countable; can read as noise or snow on a 200px Pebble

### Best for
If “fill the leftover sky” matters more than being able to tick off weeks.
