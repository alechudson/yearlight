# Observatory

## Design stance
One centered stack, with nothing competing for attention.

## Key choices
Full-width clock; dedicated date line; icon and temperature on their own line. White type, one yellow temperature accent. No weekly chart.

## Trade-offs
The cleanest everyday read, but gives up forecast detail.

## Best for
A watch face, not a dashboard.

## Interaction
Switch clear/rain/wide/no-weather samples; compare 12/24-hour time and native/2× pixels. These are browser-only controls.
