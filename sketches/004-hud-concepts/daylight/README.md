# Daylight

## Design stance
Connect the readout to the globe’s day/night story.

## Key choices
A large centered clock, a date-and-weather row, and a compact daylight ruler from sunrise to sunset. A yellow marker shows time within the daylight interval.

## Trade-offs
Adds meaningful solar context, but replaces the weekly forecast. Browser mock uses illustrative sunrise/sunset times.

## Best for
Making the whole face feel like one idea.

## Interaction
Switch clear/rain/wide/no-weather samples; compare 12/24-hour time and native/2× pixels. These are browser-only controls.
